SAHI, the tracker heuristic, calibration mathematics, velocity formula, or
experimental constants. The original monolithic source remains available under
`experiments/legacy` for line-by-line comparison.

The initial Git worktree was clean. Work was performed on branch
`refactor/project-reorganization`.

## Permanently deleted

- All `__pycache__` directories and tracked `.pyc` files: generated bytecode that
  is safely regenerated by Python.
- `pipleline_classes/best5.pt`: confirmed with SHA-256 to be byte-for-byte
  identical to the retained `models/ground_marker_yolov8.pt`.
- Empty legacy directories after their contents were moved.

No unique source, notebook, video, trained weight, research document, or data
artifact was permanently deleted.

## Extracted code

The implementation in `finalpipe3.py` was separated into detection, tracking,
pose, calibration, metric, visualization, and orchestration modules. Duplicate
imports, unreachable commented blocks, debug prints, and unused imports were not
copied into the maintained package.

## Broken dependencies fixed

- Active imports now reference a real package rather than missing modules such as
  `finalpipe` and `finalpipe2`.
- Model paths are repository-relative through `PipelineSettings`.
- Sample video paths are explicit CLI inputs.
- Marker detection now uses the actual first video frame. The legacy function
  read that frame and then incorrectly replaced it with a missing developer-local
  JPEG path.
- Output paths are configurable and parent directories are created safely.
- Dependency metadata and a Python version range were added.

## Intentionally unresolved issues

- The tracker can switch identities and assumes a detection for the selected
  athlete on every processed frame.
- FPS remains fixed at 60 rather than read from video metadata.
- Hip Y remains fixed at 1060 instead of using the detected landmark Y.
- Marker identities depend only on right-to-left X ordering and require exactly
  five useful detections.
- The 10 m × 1.22 m geometry and former 3840 × 2160 image-size argument are
  research assumptions.
- Pose estimation stops when track history and video frame indexing diverge.
- The old FastAPI prototype is not an active backend.
- `experimental_best2.pt` has no surviving code reference, so its training task
  cannot be identified safely.
- The labeled training dataset referenced by `configs/dataset.yaml` is absent.
- Historical notebooks contain stale absolute paths and imports; they remain
  unchanged as research records.

## Verification record

- Pre-refactor source syntax compilation: passed.
- Post-extraction package syntax compilation: passed.
- File hashes identified the duplicate custom model safely.
- Import/inference execution: not available in the current Python 3.14 runtime;
  core dependencies including NumPy, OpenCV, Ultralytics, MediaPipe, SAHI, pandas,
  Matplotlib, and Statsmodels are not installed.
- Full video inference: not run because dependencies are unavailable and the task
  explicitly excludes unnecessary downloads or expensive execution.
- Lightweight tests were added for the original speed formula, moving average,
  and homography application; they require the Python 3.11 environment described
  in the README.
